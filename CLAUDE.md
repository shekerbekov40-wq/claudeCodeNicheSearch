# Content planning workspace

I plan short-form video content (Instagram Reels first, TikTok second) for small local businesses and fill the plans into Notion.

## Client profiles
Client profiles live in `clients/`. When I name a client, read their file **before** researching or drafting anything, and follow it over the defaults below. If a client has no file yet, ask whether to create one.

- `clients/square-barbershop.md`: Square Barbershop (barber, Chicago + suburbs)

## How I work with clients (consultation process)
1. **Briefing:** understand the business from the inside.
2. **Analysis:** niche, target audience (pains / fears / desires / objections), competitors (reach, what's good / bad in their content).
3. **Packaging:** profile name, bio, highlights, pinned posts, booking link.
4. **Content strategy:** content types are *broad* (health, relationships, money, beauty), *expert*, *personal*, *selling*. The main way we present content is breakdowns. Each client has their own recurring segments.
5. **Execution:** a 2-week content plan in Notion.

## Content plan defaults
- Fill the client's Notion table directly (Notion connector). Fetch the database first and use the exact column names; don't create a new database unless asked.
- One row per video. The Script (title) cell is a short title; the full script goes inside the row's page.
- **Script format inside each page:** a header (segment, length, why, reference, client's role), then Look & feel, then the **Script**: numbered shots, each with its **Shot** description, **VO** and on-screen **Text** together under that shot. Then Caption, Hashtags, Location tag, Filming notes.
- Dates are short: `Sat, Sep 26`. No year, no posting time.
- Write in the language the client's content is in, even if our notes are in Russian.
- Leave clear placeholders (`[SUBURB]`, `[CLIENT TOWN]`) instead of inventing facts. Personal/founder stories come from a real interview with the client; never make them up.

## Reference links: rules
- **Only use links you have actually verified**, or links I gave you. If you can't open Instagram/TikTok (blocked in the cloud environment), say so and don't pass search-result links off as matching videos.
- Link to a specific video, never to a profile page.
- If no verified reference exists for a row, write "(add a reel you like)" and tell me.

## Research notes
- In the cloud environment, Instagram, TikTok and most websites are blocked for direct fetch; only web search works. Say that upfront in research and label what is based on search snippets.
